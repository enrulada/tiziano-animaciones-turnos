# 🎨 Demo de animaciones de confirmación de turnos - Tiziano II

Este proyecto es una demostración visual de una propuesta para mejorar
la experiencia del cliente al momento de confirmar un turno.

## 💡 Idea de la propuesta

La intención es que, cuando un turno sea confirmado correctamente,
el cliente no reciba solamente el mensaje de "Turno confirmado",
sino también una pequeña animación relacionada con el servicio reservado.

Por ejemplo:

- ✂️ Peluquería: animación de tijeras.
- 💅 Manicuría: animación relacionada con esmaltado.
- 💈 Barbería: animación del poste de barbería.
- 🪷 Estética: animación de una flor de loto.

De esta manera, además de recibir la confirmación escrita, el cliente
obtiene una referencia visual del servicio para el cual reservó su turno.

## ⚙️ Importante

Este proyecto es solamente una demo de la animación.

No modifica la lógica de reserva ni la gestión de turnos de Tiziano II.

En una futura integración con el sistema real, la animación debería
mostrarse únicamente después de que el backend confirme que el turno
fue registrado correctamente.
